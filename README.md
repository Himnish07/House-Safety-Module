# House-Safety-Module
We built a hardware Home Safety Module using digital logic—no microcontrollers! A 2-to-4 decoder manages emergency priority between fire, gas, and intrusion. A reverse-biased photodiode detects flame, an MQ-2 detects gas, and an LDR tracks motion. An NE555 timer with a D Flip-Flop frequency divider produces distinct alarm tones for each hazard.
